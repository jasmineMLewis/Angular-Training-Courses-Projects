# Create a Project
ng new <project-name>

# Install Project Dependencies
npm install

# Create a Component
ng generate component <component-name>

# Abbreviation 
ng g c <component-name> 

## To ignore test
ng g c <component-name> --skip-tests

# Run a Project
npm start
 
## Display In Browser Automatically 
To have the project display on a browser automatically use "ng serve --open"
ng serve --open
